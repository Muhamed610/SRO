# SRO-2
# Система контроля посещаемости (Мини-проект №2)

Проект разработан по дисциплине «Парадигмы программирования» для студентов Алматинского технологического университета.

## Структура модулей и соответствие лекциям:
- **Лекция 1–2 (Императивный прототип):** Реализованы базовые условия и циклы подсчёта в `logic.py`.
- **Лекция 3 (Процедурное программирование):** Выделены независимые функции с явными типами и возвращаемыми значениями (`calculate_attendance_percentage`, `filter_risk_group`).
- **Лекция 4 (Модульная организация):** Проект разбит на три независимых модуля: `models.py`, `logic.py`, `main.py`.
- **Лекция 5 (ООП):** Созданы предметные классы `Student` и `AttendanceJournal` с инкапсуляцией данных.
- **Лекция 6 (Наследование и полиморфизм):** Реализован абстрактный класс `AccessPolicy` и два взаимозаменяемых класса политик: `StandardPolicy` и `LenientPolicy`.
- **Лекция 7 (Функциональная парадигма):** Функция `filter_risk_group` написана как чистая функция без побочных эффектов.
- **Лекция 8 (Функции высшего порядка и генераторы):** Использован ленивый генератор отчётов `get_attendance_report_generator`.
